# TABI KOREA (旅コリア) - 日本人向け韓国観光総合ポータル

## 1. プロジェクト概要
本プロジェクトは、韓国を訪れる日本人旅行者をターゲットに制作された高品質な観光案内ウェブサイトです。
最新のトレンドスポット（聖水、漢南洞、益善洞など）の紹介から、ソウル観光インタラクティブ・マップ、本場K-グルメ、指さし韓国語、そして日本人旅行者が現地で直面しやすい決済（WOWPASS）、交通（T-money）、ナビゲーション（NAVERマップの必要性）、免税手続き（TAX REFUND）の実践的なノウハウまで網羅しています。

## 3. 技術スタック

- **Markup**: HTML5 (W3C標準規格準拠、セマンティックタグ活用)
- **Styling**: Tailwind CSS + Vanilla CSS (`assets/css/style.css`)
- **Script**: JavaScript (ES6+), jQuery 3.7.1, Web Storage API (`localStorage`), Clipboard API
- **Icons**: インラインSVG (デザインの統一性と読み込み高速化、絵文字不使用)
- **Typography**: Google Fonts (Noto Sans JP, Outfit)

## 4. 主な機能とパブリッシング設計ポイント

### 1) ソウル観光インタラクティブ・マップ (#map)
- 漢江（ハンガン）を挟む江北・江南の地理的感覚を視覚化したカスタムマップ。
- 8大主要拠点（聖水、漢南洞、明洞、弘大、益善洞、江南、蚕室、東大門）のピンを配置。
- ピン選択時に所要時間や見どころ、そして「NAVERマップ公式ルート検索」へのダイレクトリンクを提供。

### 2) マイ旅プランナー（お気に入り保存 & ドロワー）
- 各スポットカードのブックマークボタンをクリックすると、ブラウザの `localStorage` に即時保存。
- 画面右下のフローティングボタンから保存リストをスライドドロワーで確認・個別削除・リセット可能。
- ページ再訪問時にも保存リストが永続化されます。

### 3) 旅で使える！指さし韓国語会話カード (#phrases)
- 飲食店での注文（「이거 주세요」「덜 맵게 해주세요」）、タックスフリー確認、割り勘会計など、現地で即戦力となるフレーズを厳選。
- 日本語訳、カタカナ読み、ハングルを併記。
- ワンクリックでクリップボードにコピーされ、トースト通知を表示。

### 4) ソウルの気候・季節別おすすめ服装ガイド (#weather)
- 春夏秋冬の4シーズン切り替えタブ。
- 各季節の平均気温、おすすめの服装、必需品チェックリストを掲載。

### 5) 定番の安心機能
- 1330 観光通訳案内ホットライン（24時間日本語対応）の常時表示。
- ウォン・円 簡易換算シミュレーター（1万〜10万ウォンプリセット）。
- よくある質問（FAQ）のスライド式アコーディオン。
