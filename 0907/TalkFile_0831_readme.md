# 0831 · 焼き Family MT 안내 웹앱 (Google Apps Script)

가평 1박 2일 팀 MT 안내 페이지입니다. `Code.gs` 상단의 `MT_CONFIG` 객체 값만 수정하면 팀명·일정·장소·회비·참가자 정보가 전체 페이지에 반영됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | D-day 카운트다운, 타임테이블, 오시는 길, 준비물 체크리스트, 회비, 참가자 카드, QR 공유 섹션이 포함된 페이지 템플릿 |
| `Code.gs` | `doGet()` 진입점 + `MT_CONFIG` 설정 객체가 담긴 Apps Script 서버 코드 |
| `assets/` | QR 이미지 등 부속 파일 자리 |

## 배포 방법

1. Google Apps Script 편집기에서 `Code.gs`, `index.html` 파일을 그대로 붙여넣습니다.
2. `Code.gs` 상단의 `MT_CONFIG` 값(팀명, 일정, 장소, 회비, 참가자 등)을 수정합니다.
3. 배포 → 새 배포 → 유형: 웹 앱
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
4. 배포된 URL을 팀원들에게 공유합니다.

## 재배포 시 유의사항

내용만 수정했다면 "배포 관리 → 새 버전"으로 재배포해야 기존에 공유한 URL이 그대로 유지됩니다.
