## 파일 구성

| 파일/폴더 | 설명 |
| --- | --- |
| `index.html` | 이력서 마크업 (순수 HTML, 인라인 스타일 없음) |
| `css/style.css` | 레이아웃·타이포그래피·표·목록 스타일 |
