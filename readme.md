# HCJ — 박나온 웹 개발 작업 기록

이 저장소는 제가 직접 만들어본 웹 페이지·웹 앱들을 날짜/번호별로 모아둔 기록입니다. 포트폴리오·이력서 같은 정적 페이지부터, 구글 시트와 연동되는 서버리스 웹앱, 브라우저에서 이미지·PDF·오디오 파일을 직접 처리하는 도구까지 다양한 형태로 작업해봤고, 각 폴더에 무엇을 만들었는지와 실제로 어떻게 동작하는지를 개별 `readme.md`에 정리해두었습니다.

즉, 이 저장소는 "이런 요청이 들어오면 이 정도까지는 만들어본 적이 있다"는 걸 보여주는 작업 이력이자, 비슷한 작업이 다시 들어와도 무리 없이 이어서 할 수 있다는 근거이기도 합니다.

## 그동안 다뤄본 것들

- 프레임워크 없이 순수 HTML/CSS/JS로 반응형 UI 만들기
- `<canvas>`를 이용한 이미지 리사이즈·압축, 파형 시각화, 파티클/물리 애니메이션
- 브라우저에서 직접 파일 처리하기 — 이미지, PDF(`pdf.js`, `pdf-lib`), Office 문서(zip 구조인 `.docx`/`.pptx`를 `JSZip`으로 파싱), 오디오(Web Audio API, `lamejs`)
- `localStorage`를 활용한 간단한 데이터 저장(방명록 등)
- Google Apps Script + Google 스프레드시트를 백엔드처럼 활용하는 서버리스 웹앱
- 외부 CDN 라이브러리 연동, 그리고 라이브러리 누락·DOM id 불일치 같은 실제 버그를 찾아 고치는 디버깅
- TextRank 요약, 시드 기반 의사난수 생성 같은 알고리즘을 직접 구현
- 다국어(일본어) 콘텐츠 제작

이 정도 범위의 작업은 이미 한 번씩 만들어본 것들이라, 비슷한 요청이 다시 오면 새로 처음부터 헤매지 않고 바로 이어서 진행할 수 있습니다.
