# 🎓 교육자료 신청 및 설문조사 웹앱

Google Apps Script(GAS)를 기반으로 제작된 **교육자료 신청 및 강의 만족도 조사 웹 애플리케이션**입니다.  
사용자가 웹 폼을 통해 신청서 및 설문 결과를 제출하면, 해당 데이터가 Google 스프레드시트에 자동으로 기록됩니다.

---

## 📌 주요 기능
- **QR 코드 지원**: 스마트폰으로 QR 코드를 스캔하여 바로 접속 가능
- **신청 및 설문 폼**: 이름, 소속, 학번, 이메일, 만족도, 희망 주제, 메시지 입력
- **Google Sheets 연동**: 제출된 데이터가 지정된 구글 스프레드시트에 실시간 자동 저장
- **반응형 디자인**: 모바일 및 데스크톱 환경 모두에 최적화된 깔끔한 UI/UX
