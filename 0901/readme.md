# 🕒 스터디 시간 조율 웹앱 (Study Time Coordinator)

Google Apps Script(GAS)와 Google Spreadsheet를 활용하여 팀원들의 스터디 및 동아리 가능한 시간대를 취합하는 서버리스 웹 어플리케이션입니다.

## ✨ 주요 기능
* **구글 시트 연동 DB:** 제출된 데이터는 지정된 구글 스프레드시트에 실시간으로 자동 기록됩니다.
* **직관적인 시간표 UI:** 터치/클릭 친화적 시간표 그리드를 제공하여 요일 및 시간대별로 쉽게 가능한 시간을 선택할 수 있습니다.
* **중복 제출 방지:** '회차(주차)'와 '학번'을 조합하여 동일 회차 내 중복 제출을 실시간으로 감지하고 차단합니다.
* **반응형 웹 디자인:** Tailwind CSS 기반으로 데스크톱 및 모바일 기기 모두에 최적화된 Material Design 스타일의 깔끔한 UI를 제공합니다.

## 🛠 기술 스택
* **Backend:** Google Apps Script (JavaScript)
* **Database:** Google Spreadsheet
* **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS (CDN), Google Material Symbols

## 🚀 설치 및 배포 방법

### 1. 스프레드시트 준비
1. 새로운 Google Spreadsheet를 생성합니다.
2. 시트의 URL을 복사해 둡니다.

### 2. Apps Script 설정
1. 생성한 스프레드시트 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. 기존 생성된 `Code.gs` 파일의 내용을 지우고, 첨부된 `code.gs`의 코드를 붙여넣습니다.
3. `code.gs` 파일 상단의 `SHEET_URL` 상수에 본인이 생성한 시트의 URL을 붙여넣습니다.
4. 왼쪽 파일 메뉴의 `+` 버튼을 눌러 **[HTML]** 파일을 추가하고, 파일명을 `index.html`로 지정한 뒤 첨부된 코드를 붙여넣습니다.

### 3. 시트 헤더 초기화 (최초 1회)
1. `code.gs` 상단 툴바의 함수 선택기에서 `setupHeader`를 선택합니다.
2. **[실행]** 버튼을 클릭합니다.
3. 최초 실행 시 나타나는 권한 검토 창에서 본인 계정으로 **권한을 허용(Advanced -> Go to unsafe)** 합니다.
4. 스프레드시트로 돌아가면 A열부터 G열까지 헤더가 예쁘게 적용된 것을 확인할 수 있습니다.

### 4. 웹 앱 배포
1. 우측 상단의 **[배포] > [새 배포]**를 클릭합니다.
2. 유형 선택(톱니바퀴 아이콘)에서 **[웹 앱]**을 선택합니다.
3. 다음과 같이 설정합니다:
   * **다음 사용자로서 실행:** `나(본인 계정 이메일)`
   * **액세스 권한이 있는 사용자:** `모든 사용자`
4. **[배포]**를 클릭하고 최종 승인을 완료하면 고유한 웹 앱 URL이 생성됩니다. 이 링크를 팀원들에게 공유하세요.

## 📝 주차(회차) 변경 가이드 
새로운 스터디 주차가 시작되어 새롭게 시간 조율을 받아야 하는 경우, 다음과 같이 업데이트합니다.

1. Apps Script 편집기로 이동합니다.
2. `code.gs` 파일 19번째 줄의 `CURRENT_ROUND` 변수 값을 새로운 주차로 수정합니다.
   * `const CURRENT_ROUND = '2주차';` 
3. 우측 상단 **[배포] > [배포 관리]**를 클릭합니다.
4. 현재 배포 버전 우측의 ✏️(연필 아이콘, 수정)를 누릅니다.
5. **버전** 드롭다운에서 반드시 **[새 버전]**을 선택한 후 **[배포]**를 클릭합니다.
6. URL 변경 없이 성공적으로 화면과 데이터베이스 타겟이 새 주차로 갱신됩니다.

## 📁 파일 구성 요소
* `code.gs`: 서버 로직 (시트 연동, 중복 검증, HTML 렌더링, 데이터 저장 처리)
* `index.html`: 클라이언트 로직 (UI 렌더링, 폼 입력값 검증, Tailwind CSS 스타일링)
