# 0727 · 박나온 포트폴리오 v2 (슬라이드 네비게이션형)

0723 "Web Architect & IE" 포트폴리오를 리뉴얼한 버전입니다. 좌우 화살표(또는 방향키·스와이프)로 섹션을 한 화면씩 넘기는 가로 슬라이드형 포트폴리오이며, Home 섹션에는 터미널 타이핑 애니메이션을 넣었습니다. 0723의 네이비/스카이블루 컬러 아이덴티티를 그대로 이어받아 두 버전이 같은 사람의 포트폴리오임을 알아볼 수 있게 했습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 마크업 + 슬라이드 네비게이션/타이핑 애니메이션/스크롤 리빌 스크립트 |
| `style.css` | 전체 스타일 (터미널 UI, 슬라이드 트랙, 카드, 반응형 포함) |
| `profile.jpg` | 프로필 이미지 (플레이스홀더) |

## 주요 기능

- Home / About / Skills / Projects / Career / Contact 총 6개 섹션을 `.track`에 가로로 배치하고, 좌우 화살표 버튼·방향키·스와이프로 섹션 단위 이동
- Home 섹션의 터미널 UI에서 자기소개 문장이 한 글자씩 타이핑되는 애니메이션 (`prefers-reduced-motion` 사용자는 즉시 전체 텍스트 표시)
- `IntersectionObserver`로 각 섹션에 들어설 때 요소들이 서서히 나타나는 reveal 애니메이션
- 상단 네비게이션·하단 프로그레스 닷과 현재 섹션 동기화
- 반응형 레이아웃 및 버튼 `aria-label` 등 기본 접근성 처리
