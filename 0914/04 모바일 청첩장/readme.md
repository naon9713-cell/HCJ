# 04. 모바일 청첩장

모바일 화면에 최적화된 1페이지 웨딩 청첩장입니다. 신랑 드미트리 · 신부 로렐라이(예시 데이터)를 기준으로 제작되어 있어, 실제 사용 시 `index.html`의 텍스트와 `pictures/` 이미지, `script.js`의 계좌번호 등을 교체해야 합니다.

## 파일 구성

| 파일/폴더 | 설명 |
| --- | --- |
| `index.html` | 청첩장 전체 마크업 (Hero, 초대글, 프로필, 카운트다운, 갤러리, 오시는 길, 계좌, 방명록, 푸터) |
| `style.css` | 전체 스타일 (벚꽃 파티클, 반응형 모바일 래퍼 등) |
| `script.js` | 카운트다운, 갤러리 라이트박스, 방명록, 계좌 복사, 지도 연결, 공유 기능 스크립트 |
| `pictures/` | 신랑·신부·커플 사진 (`신랑.png`, `신부.png`, `함께1~3.png`) |
| `문구.txt` | 초대 문구 원본 텍스트 |

## 주요 기능

- 결혼식 일시까지 남은 시간을 보여주는 **카운트다운 타이머**
- 은은하게 떨어지는 **벚꽃 파티클 캔버스 애니메이션** (헤더 버튼으로 켜기/끄기)
- 사진을 클릭하면 확대해 넘겨볼 수 있는 **갤러리 라이트박스**(스와이프 지원)
- 네이버지도 / 카카오맵 / 티맵 딥링크로 연결되는 **오시는 길 버튼**
- 신랑측·신부측 계좌를 아코디언으로 펼치고 **클립보드로 복사**하는 기능
- 이름·메시지를 입력하면 **브라우저 `localStorage`에 저장**되는 방명록 (기기·브라우저 간 공유되지 않는 로컬 저장 방식)
- 청첩장 링크 복사 및 `navigator.share`(웹 공유 API) 기반 공유 버튼

## 참고

- 방명록은 서버나 DB 없이 `localStorage`만 사용하므로, 방문자가 다른 기기/브라우저로 접속하면 이전에 남긴 메시지가 보이지 않습니다.
- 실제 배포 전 이름, 날짜, 장소, 계좌번호, 사진을 교체해야 합니다.
