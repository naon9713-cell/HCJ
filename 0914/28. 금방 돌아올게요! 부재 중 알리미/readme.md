# 28. 금방 돌아올게요! 부재 중 알리미

자리를 비울 때 화면에 크게 띄워두는 "자리 비움 안내" 표시 앱입니다. 현재 일정과 복귀 예정 시간, 남은 시간을 실시간 카운트다운으로 보여줍니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 설정 화면(일정/복귀 시간 입력)과 표시 화면(카운트다운) UI |
| `style.css` | 설정 카드 및 전체화면 표시 화면 스타일 |
| `script.js` | 입력 처리, 실시간 시계·카운트다운, 화면 전환 로직 |

## 주요 기능

- 일정 문구, 복귀 시간(특정 시각 또는 "몇 시간 몇 분 후" 방식)과 기타 안내 문구 입력
- 설정 후 표시 화면으로 전환되어 **현재 시각, 복귀 예정 시간, 남은 시간(카운트다운)** 을 실시간으로 표시
- 전체화면 버튼으로 몰입형 표시 지원
- "설정 변경" 버튼으로 다시 설정 화면으로 돌아가 값 수정 가능

## 참고

- 외부 라이브러리나 서버 통신 없이 순수 자바스크립트로만 동작합니다.
