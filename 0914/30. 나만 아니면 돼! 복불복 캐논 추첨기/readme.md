# 30. 나만 아니면 돼! 복불복 캐논 추첨기

이름을 등록하면 각자의 구슬을 대포에서 발사해, 페그(장애물)에 부딪히며 떨어지는 물리 시뮬레이션으로 순위를 정하는 복불복 추첨기입니다. **가장 마지막에 도착하는 사람이 당첨**됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 이름 입력 화면, 게임(캔버스) 화면, 결과 화면 UI |
| `style.css` | 입력 카드, 게임 캔버스, 순위 패널, 결과 카드 스타일 |
| `script.js` | 이름 목록 관리, `Matter.js` 물리 월드 구성 및 추첨 게임 로직 |

## 주요 기능

- 참가자 이름을 등록/삭제 (최소 2명부터 추첨 시작 가능)
- `Matter.js` 물리 엔진으로 벽·페그(장애물)·바닥 구조를 만들고, 참가자별 구슬을 순서대로 발사
- 캔버스 위에서 구슬이 장애물에 부딪히며 떨어지는 과정을 실시간 렌더링, 도착 순서를 실시간 순위 패널에 표시
- "결과 건너뛰기(빠르게 보기)" 버튼으로 과정을 스킵하고 바로 결과 확인 가능
- 결과 화면에서 당첨자(가장 늦게 도착한 사람) 표시, 전체 도착 순서 확인, 컨페티(색종이) 효과
- "같은 명단으로 다시 추첨" 또는 "새로 입력하기"로 재시작

## 참고

- 물리 연산에 `matter.js`를 `cdnjs.cloudflare.com` CDN에서 불러오므로, **인터넷 연결이 없으면 추첨 게임이 동작하지 않습니다.**
