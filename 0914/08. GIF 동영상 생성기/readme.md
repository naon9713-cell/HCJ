# 08. GIF 동영상 생성기

동영상 파일을 업로드하면 지정한 너비·구간·FPS로 GIF 애니메이션을 만들어주는 Video to GIF 변환기입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 옵션 패널(너비/재생구간/FPS), 업로드 영역, 파일 목록 UI |
| `style.css` | 레이아웃 및 드롭존 스타일 |
| `script.js` | 비디오 프레임 캡처(`<video>` + `<canvas>`) 및 GIF 인코딩 로직 |
| `logo.png` | 헤더 로고 이미지 |

## 주요 기능

- 동영상 파일을 드래그 앤 드롭 또는 업로드 버튼으로 등록 (여러 개 동시 가능)
- GIF 너비, 재생 구간(초), FPS를 직접 설정
- 숨겨진 `<video>`/`<canvas>`로 프레임을 캡처한 뒤 `gif.js`로 GIF 인코딩
- 변환 진행률 표시 및 완료 후 GIF 다운로드

## 참고

- GIF 인코딩에 사용하는 `gif.js`, `gif.worker.js`는 로컬 파일이 아니라 `cdnjs.cloudflare.com` CDN에서 불러오므로, **인터넷 연결이 없으면 GIF 변환이 동작하지 않습니다.**
