# 31. 문서의 요점만 찾아주는 족집게 요약 앱

PDF 또는 DOCX 문서를 업로드하면 TextRank 알고리즘으로 핵심 문장을 추출해 요약해주는 문서 요약기입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 업로드/분석 중/결과 화면 UI |
| `style.css` | 요약 슬라이더, 결과 박스 등 스타일 |
| `textrank.js` | 문장 분리, 단어 중첩 기반 문장 유사도 계산, PageRank 방식의 TextRank 요약 엔진 |
| `script.js` | PDF/DOCX 텍스트 추출, 화면 전환, 요약 결과 렌더링 |

## 주요 기능

- PDF는 `pdf.js`, DOCX는 `JSZip`으로 압축을 풀어 `word/document.xml`을 파싱해 텍스트 추출
- 자체 구현한 `TextRankEngine`(Mihalcea & Tarau 2004 방식: 문장 간 단어 중첩 유사도 + PageRank 스타일 반복 계산)으로 추출적 요약 수행
- 슬라이더 또는 프리셋 버튼(1/3/5문장)으로 **요약 문장 수 조절**
- 원문에서 요약에 포함된 문장을 하이라이트해서 보여주는 기능
- 문장 수·단어 수 등 문서 통계 표시

## 참고

- 문서 파싱에 `pdf.js`, `JSZip`을 `cdnjs.cloudflare.com` CDN에서 불러오므로, **인터넷 연결이 없으면 파일 업로드 후 분석이 동작하지 않습니다.**
- 요약 알고리즘(`textrank.js`) 자체는 외부 라이브러리 없이 순수 자바스크립트로 구현되어 있습니다.
- 지원 형식은 PDF, DOCX이며 최대 50MB로 제한되어 있습니다.
