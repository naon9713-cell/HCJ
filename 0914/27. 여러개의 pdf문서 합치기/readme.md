# 27. 여러개의 pdf문서 합치기

여러 개의 PDF 파일을 업로드해 순서를 조정한 뒤 하나의 PDF로 합쳐 다운로드하는 PDF 병합기(PDF Merger)입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 업로드/파일 목록/결과 화면 UI |
| `style.css` | 파일 리스트, 드래그 정렬 스타일 |
| `script.js` | PDF 로드, 목록 관리, 드래그 앤 드롭 순서 변경, 병합 로직 |

## 주요 기능

- 여러 PDF 파일을 한 번에 업로드하고, 각 파일의 페이지 수·용량 표시
- 파일 목록을 **드래그 앤 드롭으로 순서 변경** 가능
- `pdf-lib`(`PDFDocument.create/copyPages`)로 브라우저 안에서 선택한 순서대로 페이지를 합쳐 새 PDF 생성
- 합쳐진 PDF의 총 페이지 수 표시 및 다운로드
- 파일 목록에서 개별 파일 제거, "다시 시작" 초기화 기능

## 참고

- PDF 처리에 `pdf-lib`(unpkg)와 `pdf.js`(cdnjs) CDN 라이브러리를 사용하므로, **인터넷 연결이 없으면 병합 기능이 동작하지 않습니다.**
- 병합은 서버 업로드 없이 전부 브라우저 내에서 처리됩니다.
