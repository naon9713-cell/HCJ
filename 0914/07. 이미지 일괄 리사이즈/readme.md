# 07. 이미지 일괄 리사이즈

여러 장의 이미지를 한 번에 업로드해 원하는 비율(1:1, 3:4, 4:3, 9:16, 16:9, 커스텀)로 맞추는 이미지 리사이저입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 업로드 영역, 비율/변환 방식 설정 패널, 파일 목록, 일괄 다운로드 버튼 |
| `style.css` | 드롭존, 설정 패널, 파일 리스트 스타일 |
| `script.js` | 파일 업로드 처리, 캔버스 기반 리사이즈(Padding/Crop), ZIP 일괄 다운로드 로직 |
| `logo.png` | 헤더 로고 이미지 |

## 주요 기능

- 여러 이미지 파일을 드래그 앤 드롭 또는 파일 선택으로 업로드
- 캔버스 비율(1:1 ~ 16:9, 커스텀 비율) 선택
- **Padding**(여백 추가, 색상 지정 가능) 또는 **Crop**(잘라내기) 방식 선택
- 파일별 변환 진행률 표시 및 개별 다운로드
- 전체 결과물을 ZIP으로 묶어 일괄 다운로드하는 버튼 (`JSZip` 라이브러리 필요)

## 알려진 문제

- `index.html`에서 `jszip.min.js`를 불러오도록 되어 있지만 해당 파일이 폴더에 없어 **전체 ZIP 다운로드 기능은 동작하지 않습니다.** (코드 자체에 이 경우를 대비한 안내 알림은 구현되어 있습니다.)
- 개별 이미지 리사이즈/다운로드는 `<canvas>`만으로 동작하므로 정상적으로 사용할 수 있습니다.

## 참고

- 이전에는 진입 파일명이 `indez.html`로 오타가 있어 `index.html`을 자동으로 찾는 배포 환경(GitHub Pages 등)에서 페이지가 열리지 않았습니다. `index.html`로 이름을 수정했습니다.
