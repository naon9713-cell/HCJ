# 23. 오늘의 운세를 알려주는 나나도사

이름·생년월일·성별과 오행(불/물/나무/땅/바람) 중 끌리는 하나를 선택하면, 재미로 보는 오늘의 운세를 보여주는 웹 앱입니다.

## 파일 구성

| 파일/폴더 | 설명 |
| --- | --- |
| `index.html` | 정보 입력(1단계) → 오행 선택(2단계) → 결과(3단계) 화면 마크업 |
| `style.css` | 카드형 스텝 UI, 오행 카드, 결과 화면 스타일 |
| `script.js` | 오행별 자체 제작 운세 문구 데이터, 결과 생성 로직 |
| `docs/` | 작업 확인용 스크린샷 보관 폴더 (앱 실행에는 사용되지 않음) |

## 주요 기능

- 이름·생년월일·성별을 입력하고 오행 5가지 중 하나를 선택하는 단계별(스텝) 진행
- 이름+생년월일+선택한 오행 값을 문자열 해시로 시드(seed)를 만들어 `mulberry32` 의사난수 생성기로 결과를 결정 → **같은 입력이면 항상 같은 결과**가 나오는 방식 (실제 사주/점성술 계산이 아닌, 자체 제작한 텍스트 뱅크 기반의 재미용 콘텐츠)
- 총운, 애정운, 재물운, 건강운, 학업·직장운 카테고리별 코멘트 표시
- 오행별 행운의 색/숫자/아이템/방향 정보 제공

## 참고

- 외부 라이브러리나 서버 통신 없이 순수 프론트엔드 로직(문자열 해시 + 의사난수)으로만 동작합니다.
