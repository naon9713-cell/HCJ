# 24. 글자 수를 세어 주는 웹 앱

텍스트를 입력하면 글자 수, 공백 제외 글자 수, 바이트 수(한글 2byte 기준), 단어 수, 줄 수를 실시간으로 계산해주는 글자수 세기 도구입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 텍스트 입력 영역과 통계 카드 UI |
| `style.css` | 카드형 통계 레이아웃 스타일 |
| `script.js` | 글자/바이트/단어/줄 수 계산 로직 |

## 주요 기능

- 입력 즉시(input 이벤트) 통계 갱신: **글자 수(공백 포함/제외), 바이트 수, 단어 수, 줄 수**
- 한글(완성형 가~힣, 자음/모음)은 2byte, 그 외 문자는 1byte로 계산
- 한글 글자 수 / 영문·숫자·기타 글자 수를 별도로 표시
- "전체 지우기" 버튼으로 입력 초기화

## 참고

- 외부 라이브러리나 서버 통신 없이 순수 자바스크립트로만 동작합니다.
