# 05. smartQR

URL을 입력하면 실시간으로 QR코드를 생성하고, 클릭 한 번으로 고화질 JPG 파일로 다운로드할 수 있는 QR코드 생성기입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | QR 생성기 마크업 (헤더, URL 입력, QR 카드 미리보기) |
| `style.css` | 인터랙티브 그라디언트 배경, QR 카드, 반응형 스타일 |
| `script.js` | 입력 처리, QR 생성/다운로드, 링크 복사, 마우스 반응형 배경 스크립트 |
| `qrcode.min.js` | QR코드 생성 라이브러리 (로컬 내장, CDN 미사용) |
| `logo.png` | 헤더 로고 이미지 |

## 주요 기능

- URL 입력 시 `qrcode.min.js`를 이용해 실시간으로 QR코드 생성
- 생성된 QR코드를 고화질 **JPG 파일로 다운로드**
- 입력한 URL을 **클립보드로 복사**하는 버튼
- 마우스 커서 위치에 반응하는 인터랙티브 그라디언트/오로라 배경 효과
- 로고 클릭 시 초기 화면으로 리셋
