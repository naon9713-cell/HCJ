# 25. 문서 파일 통계 분석 시스템

PDF 또는 DOCX 파일을 업로드하면 글자 수, 단어 수, 공백 개수, 이미지 개수 등을 분석해주는 문서 분석기(문서 글자 수 분석기)입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 업로드/로딩/결과/오류 화면 UI |
| `style.css` | 카드형 결과 통계 및 화면 전환 스타일 |
| `script.js` | PDF·DOCX 파싱 및 통계 계산 로직 |

## 주요 기능

- PDF: `pdf.js`로 텍스트를 추출하고, 페이지 내 이미지 객체(`paintImageXObject` 등)를 세어 이미지 개수 표시, 페이지 수도 함께 표시
- DOCX: `JSZip`으로 압축을 풀어 `word/document.xml`을 파싱해 텍스트 추출, 문서 내 이미지 파일 개수 표시
- 공통 통계: 글자 수(공백 포함/제외), 단어 수, 공백 개수
- 추출된 텍스트 미리보기(`<details>`로 펼쳐보기)
- 분석 중 로딩 화면, 실패 시 오류 화면과 재시도 버튼

## 참고

- `pdf.js`, `JSZip` 라이브러리를 `cdnjs.cloudflare.com` CDN에서 불러오므로, **인터넷 연결이 없으면 분석 기능이 동작하지 않습니다.**
- 지원 형식은 PDF, DOCX이며 최대 50MB로 제한되어 있습니다(구 형식 .doc, .ppt 등은 지원하지 않음).
