# 29. keep fit bmi

성별·키·몸무게를 입력하면 BMI와 비만도, 목표 체중을 계산해주는 BMI 계산기입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 입력 화면(성별/키/몸무게)과 결과 화면 UI |
| `style.css` | 카드형 입력·결과 레이아웃 스타일 |
| `script.js` | BMI 및 표준체중·목표체중 계산 로직 |

## 주요 기능

- 성별(남/여), 키(cm), 몸무게(kg) 입력 후 BMI 계산
- BMI 수치와 비만도 카테고리(저체중/정상/과체중/비만 등) 표시
- 표준체중(키(m)² × 22[남]/21[여]) 및 현재 비만도(%) 계산
- 비만도 90% / 100%(표준) / 110% 기준의 목표 체중과 현재 체중 대비 증감량 표시
- "다시 계산하기" 버튼으로 재입력

## 참고

- 결과는 일반적인 계산식 기반의 참고용 정보이며, 의학적 진단을 대체하지 않는다는 안내 문구가 포함되어 있습니다.
- 외부 라이브러리나 서버 통신 없이 순수 자바스크립트로만 동작합니다.
