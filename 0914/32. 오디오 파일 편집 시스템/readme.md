# 32. 오디오 파일 편집 시스템

오디오 파일(mp3/wav/ogg/m4a/aac/flac)을 업로드해 파형을 보며 구간을 자르고(트림), 볼륨을 조절한 뒤 WAV 또는 MP3로 내보내는 오디오 편집기입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 업로드/분석 중/편집기/내보내기/완료 화면 UI |
| `style.css` | 파형 캔버스, 트림 핸들, 편집 컨트롤 스타일 |
| `script.js` | 오디오 디코딩, 파형 렌더링, 트림/볼륨 처리, WAV 인코딩, 내보내기 로직 |

## 주요 기능

- `AudioContext`로 오디오 파일을 디코딩하고 **파형(waveform)을 캔버스에 시각화**
- 드래그 가능한 시작/끝 핸들로 **구간 트림(자르기)** 설정, 트림 구간만 미리듣기 또는 전체 재생
- 볼륨을 0~200%로 조절 (100% 초과 시 **클리핑(음 찌그러짐) 경고** 표시)
- 내보내기 형식으로 **WAV**(자체 구현한 PCM 인코더) 또는 **MP3**(`lamejs`, 비트레이트 선택 가능) 지원
- 내보내기 진행률 표시, 완료 후 결과 미리듣기 및 다운로드, 이어서 편집하기

## 참고

- MP3 인코딩에 `lamejs`를 `cdnjs.cloudflare.com` CDN에서 불러오므로, **인터넷 연결이 없으면 MP3로 내보내기가 동작하지 않습니다.** (WAV 내보내기는 외부 라이브러리 없이 동작합니다.)
