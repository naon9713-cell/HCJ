# 26. lorem lpsum 생성기

## ⚠️ 폴더명과 실제 내용 불일치

이 폴더의 `index.html`/`script.js`/`style.css`는 폴더명(lorem ipsum 생성기)과 달리 **24번 폴더("글자 수를 세어 주는 웹 앱")와 완전히 동일한 파일**입니다. 실제로는 "Lorem Ipsum 생성기" 기능이 구현되어 있지 않고, 텍스트 글자/바이트/단어/줄 수를 세는 앱이 그대로 들어있습니다.

이 readme는 폴더명이 아닌 **실제 코드 내용**을 기준으로 작성했습니다(과장 없이 있는 그대로 기술).

## 실제 구현된 기능 (글자 수 세기)

- 텍스트 입력 시 실시간으로 글자 수(공백 포함/제외), 바이트 수(한글 2byte 기준), 단어 수, 줄 수 계산
- 한글/기타 문자 구분 카운트
- "전체 지우기" 버튼

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 텍스트 입력 영역과 통계 카드 UI (24번 폴더와 동일) |
| `style.css` | 카드형 통계 레이아웃 스타일 (24번 폴더와 동일) |
| `script.js` | 글자/바이트/단어/줄 수 계산 로직 (24번 폴더와 동일) |

## 제안

실제 "lorem ipsum 생성기" 기능이 필요하다면 새로 구현하거나, 다른 정상 폴더의 코드를 이 폴더에 옮겨야 합니다. 이 정리 작업에서는 코드를 임의로 새로 작성하지 않고 문제 상황만 정확히 기록했습니다.
